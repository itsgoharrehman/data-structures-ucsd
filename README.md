# data-structures-ucsd

Algorithmic implementations and coursework submissions for the "Data Structures" course by the University of California San Diego, part of the Computer Science Data Structures and Algorithms Specialization.

## Core Data Structures Covered

* **Priority Queues & Disjoint Sets**: Binary min/max heaps, build-heap in linear time, disjoint set union with path compression and rank heuristics.
* **Hash Tables & Hash Functions**: Direct addressing, chaining, Rabin-Karp substring search with rolling polynomial hashing.
* **Binary Search Trees (BST)**: Tree traversals (in-order, pre-order, post-order), AVL self-balancing trees, Splay trees, and range sum queries.

## Architecture and Stack

* **Language**: Python 3.10+
* **Benchmarking**: Automated unit test suites with rigorous memory and execution time limits
